# ASCENSION — Private Hunter System

Open index.html in a browser to explore, or upload all files to a static host (GitHub Pages, Cloudflare Pages) for iPhone Add to Home Screen.

## New System AI tab
- Uses a free manual ChatGPT handoff (copy prompt, open ChatGPT, paste generated JSON).
- Imports validated 7-day meal plans directly into Meal Planner and Inventory.
- Workout and progress prompts use your locally saved logs.
- There is NO live account connection or automatic AI API call. Do not paste account credentials into the app.

## For a real ChatGPT plan sign-in
Follow https://developers.openai.com/siwc/quickstart and register a supported open-source/private client. The authentication must use OpenAI's supported flow and the device-local user-controlled token storage requirements. Do not hard-code API keys or collect ChatGPT passwords.

## Local privacy
Data is stored in browser localStorage. Export backups in Setup. A hosted static site does not by itself create accounts or cloud sync.
